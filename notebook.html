📐 Linear Algebra Exam Quick Reference Sheet

Core mathematical theorems, formulas, and definitions from LA_Notebook_1.ipynb (Mathematics-3, Newton School of Technology).

1. The Fundamental Trichotomy Theorem

Any linear system $Ax = b$ over $\mathbb{R}$ has strictly:

  • Zero solutions: Inconsistent system. Parallel distinct planes or lines with no mutual intersection point. $\text{rank}(A) < \text{rank}([A|b])$.
  • Exactly one unique solution: Consistent independent system. $\det(A) \neq 0$, $\text{rank}(A) = \text{rank}([A|b]) = n$.
  • Infinitely many solutions: Consistent dependent system. Planes intersect along an entire line or coincide. $\text{rank}(A) = \text{rank}([A|b]) < n$.

2. Row-Verse vs Column-Verse

Row Picture: Each equation represents a geometric hyperplane in $\mathbb{R}^n$. The solution is the point(s) where all hyperplanes intersect simultaneously.

Column Picture: $x_1 \mathbf{a}_1 + x_2 \mathbf{a}_2 + \dots + x_n \mathbf{a}_n = \mathbf{b}$. Finding scalars to stretch and add column vectors to hit the target vector $\mathbf{b}$.

3. Matrix Multiplication (4 Perspectives)

  • Compatibility: $(m \times k) \times (k \times n) = (m \times n)$. Inner dimensions must match!
  • Entry-wise: $c_{ij} = \sum_{r=1}^k a_{ir} b_{rj}$ (Row $i$ dot Column $j$).
  • Column view: Columns of $C$ are linear combinations of columns of $A$.
  • Row view: Rows of $C$ are linear combinations of rows of $B$.
  • Outer Product view: $C = \sum_{r=1}^k (\text{col}_r A)(\text{row}_r B)$.

4. 10 Vector Space Axioms

For all $\mathbf{u}, \mathbf{v}, \mathbf{w} \in V$ and scalars $c, d \in \mathbb{R}$:

  1. $\mathbf{u} + \mathbf{v} \in V$ (Closure $+ing$)
  2. $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
  3. $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
  4. $\exists \mathbf{0} \in V : \mathbf{u} + \mathbf{0} = \mathbf{u}$
  5. $\exists (-\mathbf{u}) : \mathbf{u} + (-\mathbf{u}) = \mathbf{0}$
  6. $c\mathbf{u} \in V$ (Closure $\times$)
  7. $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$
  8. $(c + d)\mathbf{u} = c\mathbf{u} + d\mathbf{u}$
  9. $c(d\mathbf{u}) = (cd)\mathbf{u}$
  10. $1\mathbf{u} = \mathbf{u}$

5. Linear Independence & Span

Span: $\text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_k\} = \{c_1\mathbf{v}_1 + \dots + c_k\mathbf{v}_k \mid c_i \in \mathbb{R}\}$.

Linear Independence: The vectors are linearly independent if and only if $c_1\mathbf{v}_1 + \dots + c_k\mathbf{v}_k = \mathbf{0}$ has only the trivial solution $c_1 = \dots = c_k = 0$.
